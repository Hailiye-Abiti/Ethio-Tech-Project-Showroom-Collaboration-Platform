Ethio-Tech Project Showroom is a full-stack web application designed to connect local developers, tech enthusiasts, and computer science students in Ethiopia. The platform serves as a centralized hub where users can showcase their software development projects, share live demos/source code, discover peers with similar tech stacks, and foster collaborative learning.

Key Features:

Project Showcase (CRUD): Developers can easily publish, edit, and manage their web, mobile, or desktop applications with titles, descriptions, tech tags, and screenshots.

Advanced Search & Filtering: Instantly search and filter projects based on specific technology stacks (e.g., PHP, React, Flutter, Python, MySQL).

Interactive Community Engagement: Users can view detailed project insights and engage through feedback and comments.

Responsive Modern UI: Built with clean, modern HTML, CSS (Flexbox/Grid), and JavaScript, ensuring seamless mobile and desktop responsiveness.

Robust Back-End & Database: Powered by PHP and MySQL to securely handle data storage, user requests, and dynamic content rendering.

Tech Stack:

Front-end: HTML5, CSS3, JavaScript

Back-end: PHP

Database: MySQL
